# Text-to-Speech Converter

A stylish and responsive **Text-to-Speech (TTS) web application** that converts any text input into spoken audio using the browser's built-in speech synthesis capabilities.

This project leverages **JavaScript's `SpeechSynthesis` API**, HTML, and CSS to provide a smooth, user-friendly experience.

---

## 🚀 Features

- **Real-time Text-to-Speech:** Converts written text into spoken words instantly.
- **Voice Selection:** Choose from the available voices on your device.
- **Responsive Design:** Works on desktop and mobile screens.
- **Customizable Styling:** Modern glassmorphism design with smooth hover effects.
- **Validation:** Alerts users if the textarea is empty before converting.
